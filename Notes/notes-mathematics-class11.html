Chapter 1: Sets

Introduction to sets, their representation, and operations.

Key Concepts

  • Set: A well-defined collection of distinct objects.
  • Representation: Roster/Tabular form (elements listed, e.g., A = {1, 2, 3}) and Set-builder form (property stated, e.g., A = {x : x is a natural number < 4}).
  • Types of Sets: Empty set (Φ), Finite/Infinite sets, Equal sets, Subsets (A ⊆ B), Power set (P(A), has 2ⁿ elements), Universal set (U).
  • Operations on Sets:
    • Union (A ∪ B): Elements in A or B.
    • Intersection (A ∩ B): Elements in both A and B.
    • Difference (A - B): Elements in A but not in B.
    • Complement (A'): Elements in U but not in A.
  • De Morgan's Laws: (A ∪ B)' = A' ∩ B' and (A ∩ B)' = A' ∪ B'.

Important Formula

n(A ∪ B) = n(A) + n(B) - n(A ∩ B)

Chapter 2: Relations and Functions

Cartesian products, relations, and various types of functions.

Key Concepts

  • Cartesian Product (A × B): Set of all ordered pairs (a, b) where a ∈ A and b ∈ B. If n(A)=p, n(B)=q, then n(A×B)=pq.
  • Relation (R): A subset of A × B. Domain (set of first elements), Range (set of second elements), Codomain (entire set B).
  • Function: A relation where every element of set A has one and only one image in set B. (f: A → B).
  • Types of Functions:
    • Identity: f(x) = x
    • Constant: f(x) = c
    • Polynomial: f(x) = a₀ + a₁x + ... + aₙxⁿ
    • Modulus: f(x) = |x| (x if x≥0, -x if x<0)
    • Signum: f(x) = |x|/x for x≠0, 0 for x=0
    • Greatest Integer: f(x) = [x] (greatest integer ≤ x)

Chapter 3: Trigonometric Functions

Angle measurements and trigonometric identities.

Key Concepts

  • Angles: Radian measure vs Degree measure. (π radians = 180°). Arc length l = rθ.
  • Signs of Trig Functions: ASTC Rule (All positive in 1st quadrant, Sine in 2nd, Tangent in 3rd, Cosine in 4th).

Trigonometric Identities

  • sin²x + cos²x = 1, sec²x - tan²x = 1, cosec²x - cot²x = 1
  • sin(A ± B) = sinA cosB ± cosA sinB
  • cos(A ± B) = cosA cosB ∓ sinA sinB
  • tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA tanB)
  • sin 2A = 2 sinA cosA = 2 tanA / (1 + tan²A)
  • cos 2A = cos²A - sin²A = 2 cos²A - 1 = 1 - 2 sin²A
  • tan 2A = 2 tanA / (1 - tan²A)

Chapter 5: Complex Numbers and Quadratic Equations

Numbers of the form a + ib and solving quadratics with complex roots.

Key Concepts

  • Imaginary Unit: i = √(-1), so i² = -1, i³ = -i, i⁴ = 1.
  • Complex Number: z = a + ib. Real part Re(z) = a, Imaginary part Im(z) = b.
  • Conjugate (z̄): a - ib.
  • Modulus (|z|): √(a² + b²). Note: z·z̄ = |z|².
  • Argand Plane & Polar Form: z = r(cosθ + i sinθ), where r = |z| and θ is the principal argument (-π < θ ≤ π).
  • Quadratic Equations: For ax² + bx + c = 0, if Discriminant D = b² - 4ac < 0, the roots are complex: x = (-b ± i√|D|) / 2a.

Chapter 6: Linear Inequalities

Solving and graphing inequalities in one and two variables.

Key Concepts

  • Rules: You can add/subtract the same number on both sides. You can multiply/divide by a positive number. Crucial: Multiplying/dividing by a negative number reverses the inequality sign!
  • Graphical Solution (1 Variable): Represented on a number line. Open circle for < or >, closed circle for ≤ or ≥.
  • Graphical Solution (2 Variables): Represented on a Cartesian plane. ax + by < c represents a half-plane. Use a test point (like 0,0) to determine which side to shade.

Chapter 7: Permutations and Combinations

Counting principles and arrangements.

Key Concepts

  • Fundamental Principle of Counting: If event A can occur in m ways and event B in n ways, both can occur in m × n ways (Multiplication rule) or m + n ways (Addition rule, if mutually exclusive).
  • Factorial: n! = n × (n-1) × (n-2) × ... × 1. (0! = 1).

Important Formulae

  • Permutation (Arrangement/Order matters): ⁿP_r = n! / (n-r)!
  • Combination (Selection/Order doesn't matter): ⁿC_r = n! / (r! (n-r)!)
  • Properties: ⁿC_r = ⁿC_{n-r}
  • Permutations with repetition: n! / (p₁! p₂! ...) where p₁, p₂ are identical objects.

Chapter 8: Binomial Theorem

Expansion of binomials raised to positive integral powers.

Key Concepts

  • Binomial Theorem: (x + y)ⁿ = ⁿC₀ xⁿ + ⁿC₁ xⁿ⁻¹y + ⁿC₂ xⁿ⁻²y² + ... + ⁿCₙ yⁿ.
  • General Term: T_{r+1} = ⁿC_r x^{n-r} y^r.
  • Number of terms: The expansion of (x + y)ⁿ has (n + 1) terms.
  • Middle Term:
    • If n is even, the middle term is T_{(n/2)+1}.
    • If n is odd, there are two middle terms: T_{(n+1)/2} and T_{(n+3)/2}.

Chapter 9: Sequences and Series

Arithmetic and Geometric progressions.

Key Concepts

  • Arithmetic Progression (A.P.): Difference between consecutive terms is constant (d).
    • n-th term: aₙ = a + (n-1)d
    • Sum of n terms: Sₙ = (n/2)[2a + (n-1)d] = (n/2)(a + l)
    • Arithmetic Mean (AM) between a and b: (a+b)/2
  • Geometric Progression (G.P.): Ratio of consecutive terms is constant (r).
    • n-th term: aₙ = a·rⁿ⁻¹
    • Sum of n terms: Sₙ = a(1-rⁿ)/(1-r) for r < 1, or a(rⁿ-1)/(r-1) for r > 1.
    • Sum of infinite G.P. (if |r| < 1): S_∞ = a / (1-r)
    • Geometric Mean (GM) between a and b: √(ab)
  • Relation between AM and GM: AM ≥ GM.

Chapter 10: Straight Lines

Coordinate geometry of lines.

Key Concepts

  • Distance Formula: d = √[(x₂-x₁)² + (y₂-y₁)²]
  • Section Formula: x = (mx₂ + nx₁)/(m+n), y = (my₂ + ny₁)/(m+n)
  • Slope (m): m = tan θ = (y₂-y₁)/(x₂-x₁)
  • Forms of Line Equation:
    • Slope-Intercept: y = mx + c
    • Point-Slope: y - y₁ = m(x - x₁)
    • Two-Point: y - y₁ = [(y₂-y₁)/(x₂-x₁)](x - x₁)
    • Intercept Form: (x/a) + (y/b) = 1
    • Normal Form: x cosω + y sinω = p
  • Angle between lines: tan θ = |(m₂ - m₁) / (1 + m₁m₂)|. Lines are parallel if m₁=m₂, perpendicular if m₁m₂=-1.
  • Distance of point from line: d = |Ax₁ + By₁ + C| / √(A² + B²)

Chapter 11: Conic Sections

Curves obtained by intersecting a cone with a plane.

Key Concepts

  • Circle: Set of points equidistant from a center. Eq: (x-h)² + (y-k)² = r².
  • Parabola: Set of points equidistant from a focus and a directrix.
    • Standard eq: y² = 4ax (Focus: (a,0), Directrix: x=-a, Latus Rectum: 4a).
  • Ellipse: Sum of distances from two foci is constant.
    • Eq: (x²/a²) + (y²/b²) = 1. Eccentricity e = √(1 - b²/a²). Latus Rectum: 2b²/a.
  • Hyperbola: Difference of distances from two foci is constant.
    • Eq: (x²/a²) - (y²/b²) = 1. Eccentricity e = √(1 + b²/a²). Latus Rectum: 2b²/a.

Chapter 12: Introduction to Three Dimensional Geometry

Coordinate geometry in 3D space.

Key Concepts

  • Coordinate Axes/Planes: X, Y, Z axes form 3 coordinate planes (XY, YZ, ZX) dividing space into 8 octants.
  • Coordinates of a point: P(x, y, z).
  • Distance Formula: d = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]
  • Section Formula: Coordinates of point dividing segment in ratio m:n are
    ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)).
  • Centroid of a Triangle: ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3, (z₁+z₂+z₃)/3).

Chapter 13: Limits and Derivatives

Foundation of calculus.

Key Concepts

  • Limits: Value a function approaches as x approaches a value. Standard limits:
    • lim(x→a) (xⁿ - aⁿ)/(x - a) = n·aⁿ⁻¹
    • lim(x→0) (sin x)/x = 1
    • lim(x→0) (tan x)/x = 1
    • lim(x→0) (e^x - 1)/x = 1
  • Derivatives: Rate of change. First principle: f'(x) = lim(h→0) [f(x+h) - f(x)]/h.

Derivative Rules

  • d/dx (xⁿ) = n·xⁿ⁻¹
  • d/dx (sin x) = cos x, d/dx (cos x) = -sin x
  • Product Rule: d/dx (uv) = u'v + uv'
  • Quotient Rule: d/dx (u/v) = (u'v - uv') / v²

Chapter 14: Statistics

Measures of dispersion.

Key Concepts

  • Measures of Dispersion: Range, Mean Deviation, Variance, Standard Deviation. Shows how scattered data is around the central value (mean/median).
  • Mean Deviation: MD = (Σ|x_i - x̄|) / n for ungrouped data. For grouped data: MD = (Σ f_i|x_i - x̄|) / N.
  • Variance (σ²): Mean of squares of deviations from mean. σ² = (Σ(x_i - x̄)²) / n.
  • Standard Deviation (σ): Positive square root of variance. Most reliable measure of dispersion.
  • Coefficient of Variation (CV): CV = (σ / x̄) × 100. Used to compare variability of two series. Series with higher CV is more variable (less consistent).

Chapter 15: Probability

Axiomatic approach to probability.

Key Concepts

  • Sample Space (S): Set of all possible outcomes of a random experiment.
  • Event (E): A subset of the sample space. Types: Impossible event (Φ), Sure event (S), Simple event (one outcome), Compound event.
  • Mutually Exclusive Events: Cannot occur simultaneously (A ∩ B = Φ).
  • Exhaustive Events: Their union is the sample space (A ∪ B = S).
  • Axiomatic Probability: P(E) = n(E) / n(S). Note: 0 ≤ P(E) ≤ 1 and P(S) = 1.
  • Addition Theorem: P(A ∪ B) = P(A) + P(B) - P(A ∩ B). If mutually exclusive, P(A ∪ B) = P(A) + P(B).
  • Complement: P(A') = 1 - P(A).
