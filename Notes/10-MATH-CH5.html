Arithmetic Progressions High Weightage Chapter

Why this chapter is important? Arithmetic Progressions is a scoring chapter that teaches you to identify patterns in sequences, find any term, and calculate sums. It forms the foundation for more advanced topics in higher classes and carries significant weightage in board exams.

1.1 What is a Sequence?

A sequence is an arrangement of numbers or objects in a definite order. For example: 2, 4, 6, 8, ... or 5, 10, 15, 20, ...

1.2 What is an Arithmetic Progression (AP)?

A sequence is called an Arithmetic Progression if the difference between any two consecutive terms is constant. This constant difference is called the common difference (d) [citation:7].

a₂ − a₁ = a₃ − a₂ = a₄ − a₃ = ... = d (constant)

General form of an AP: a, a + d, a + 2d, a + 3d, ... where a is the first term and d is the common difference.

1.3 Identifying an AP

Example 1: 4, 10, 16, 22, ...

Here, 10 − 4 = 6, 16 − 10 = 6, 22 − 16 = 6. Since the difference is constant (6), it is an AP with d = 6 [citation:18].

Example 2: 1, -1, -3, -5, ...

Here, -1 − 1 = -2, -3 − (-1) = -2, -5 − (-3) = -2. Since the difference is constant (-2), it is an AP with d = -2 [citation:18].

Example 3 (Not an AP): -2, 2, -2, 2, ...

Here, 2 − (-2) = 4, -2 − 2 = -4. The differences alternate, so it is not an AP [citation:18].

🎯 Key Points:
  • The common difference d can be positive, negative, or zero [citation:13].
  • If d > 0, the AP is increasing. If d < 0, the AP is decreasing. If d = 0, all terms are equal.
  • An AP is defined by its first term (a) and common difference (d).

2. nth Term of an Arithmetic Progression

The formula to find the nth term (general term) of an AP is [citation:2][citation:8]:

aₙ = a + (n − 1)d

Where:

  • aₙ = nth term
  • a = first term
  • n = term number (position)
  • d = common difference

2.1 Solved Examples

Example 1: Find the 12th term of the AP 5, 9, 13, 17, ... [citation:13]

Solution:

Here, a = 5, d = 4, n = 12

a₁₂ = a + (12 − 1) × d = 5 + 11 × 4 = 5 + 44 = 49

The 12th term is 49.

Example 2: Find the 10th term of the AP: 2, 7, 12, ... [citation:18]

Solution:

Here, a = 2, d = 5 (since 7 − 2 = 5), n = 10

a₁₀ = 2 + (10 − 1) × 5 = 2 + 9 × 5 = 2 + 45 = 47

Example 3: Which term of the AP: 3, 8, 13, 18, ... is 78? [citation:16]

Solution:

Here, a = 3, d = 5, aₙ = 78

78 = 3 + (n − 1) × 5

75 = (n − 1) × 5

n − 1 = 15 → n = 16

The 16th term is 78.

2.2 Finding Number of Terms in an AP

If the last term (l) is known, the number of terms can be found using [citation:13]:

n = ((l − a) / d) + 1
Example: How many terms are there in the AP 3, 7, 11, ..., 99? [citation:13]

Solution:

Here, a = 3, l = 99, d = 4

n = ((99 − 3) / 4) + 1 = (96/4) + 1 = 24 + 1 = 25

There are 25 terms.

3. Sum of First n Terms of an AP

There are two formulas to find the sum of the first n terms of an AP [citation:2][citation:8]:

Sₙ = n/2 [2a + (n − 1)d]

Use this when first term (a), common difference (d), and number of terms (n) are known.

Sₙ = n/2 (a + l)

Use this when first term (a), last term (l), and number of terms (n) are known.

3.1 Solved Examples

Example 1: Find the sum of the first 20 terms of the AP 7, 10, 13, 16, ... [citation:13]

Solution:

Here, a = 7, d = 3, n = 20

S₂₀ = 20/2 [2(7) + (20 − 1) × 3] = 10 [14 + 57] = 10 × 71 = 710

Example 2: Find the sum of the first 20 terms of an AP where a = 10 and d = 5. [citation:19]

Solution:

S₂₀ = 20/2 [2(10) + (20 − 1) × 5] = 10 [20 + 95] = 10 × 115 = 1150

3.2 Finding n When Sum is Given

Example: How many terms of the AP: 9, 17, 25, ... must be taken to give a sum of 636? [citation:10]

Solution:

Here, a = 9, d = 8, Sₙ = 636

636 = n/2 [2(9) + (n − 1) × 8]

636 = n/2 [18 + 8n − 8]

636 = n/2 [8n + 10]

1272 = n(8n + 10)

4n² + 5n − 636 = 0

Solving this quadratic: n = 12 (negative root is rejected)

4. Special Sums (Important for Exams)

4.1 Sum of First n Natural Numbers

The positive integers 1, 2, 3, ... form an AP with a = 1 and d = 1. The sum is [citation:3][citation:9]:

Sₙ = n(n + 1) / 2
Example: Find the sum of the first 50 natural numbers. [citation:13]

Solution:

S₅₀ = 50(50 + 1) / 2 = 50 × 51 / 2 = 25 × 51 = 1275

🎯 Remember: This formula is useful for adding natural numbers quickly and is a special case of the AP sum formula with a = 1 and d = 1.

5. Word Problems (Application-Based)

5.1 Types of Word Problems

  • Counting Problems: Number of terms in a sequence (e.g., how many three-digit numbers are divisible by 7) [citation:1]
  • Real-life Applications: Taxi fare, salary increments, ladder rungs [citation:12][citation:4]
  • Finding Specific Terms: Which term of an AP is a given value
Example 1: How many three-digit numbers are divisible by 7? [citation:1]

Solution:

Smallest three-digit multiple of 7 = 105

Largest three-digit multiple of 7 = 994

AP: 105, 112, 119, ..., 994

Here, a = 105, d = 7, aₙ = 994

994 = 105 + (n − 1) × 7 → 889 = 7(n − 1) → n − 1 = 127 → n = 128

Example 2: How many multiples of 4 lie between 10 and 250? [citation:1]

Solution:

Smallest multiple = 12, Largest multiple = 248

AP: 12, 16, 20, ..., 248

Here, a = 12, d = 4, aₙ = 248

248 = 12 + (n − 1) × 4 → 236 = 4(n − 1) → n − 1 = 59 → n = 60

Example 3: A ladder has rungs 25 cm apart. The rungs decrease uniformly in length from 45 cm at the bottom to 25 cm at the top. Find the total length of wood required. [citation:4]

(This is a classic NCERT problem — the rungs form an AP with decreasing lengths.)

6. Most Repeated Previous Year Questions (CBSE)

  1. (2022) In an AP, if a = 50, d = -4 and Sₙ = 0, then find the value of n. [1 Mark] [citation:17]
  2. (2022) Find the sum of the first twelve 2-digit multiples of 7, using an AP. [2 Marks] [citation:17]
  3. (CBSE 2015) If the sum of the first n terms of an AP is (1/2)[3n² + 7n], then find its nth term. Hence write its 20th term. [3 Marks] [citation:11]
  4. (NCERT) Which term of the AP: 121, 117, 113, ... is its first negative term? [2 Marks] [citation:4]
  5. (NCERT) The sum of the third and the seventh terms of an AP is 6 and their product is 8. Find the sum of the first sixteen terms. [3 Marks] [citation:4]
  6. (NCERT) Find the 31st term of an AP whose 11th term is 38 and 16th term is 73. [2 Marks] [citation:16]
  7. (NCERT) An AP consists of 50 terms of which 3rd term is 12 and the last term is 106. Find the 29th term. [2 Marks] [citation:16]
  8. (NCERT) If the 3rd and the 9th term of an AP are 4 and -8 respectively, which term of this AP is zero? [2 Marks] [citation:16]
  9. (NCERT) The 17th term of an AP exceeds its 10th term by 7. Find the common difference. [1 Mark] [citation:16]

Quick Revision - At a Glance

🎯 Key Formulas:
  • Common Difference: d = a₂ − a₁ = a₃ − a₂ = ...
  • nth Term: aₙ = a + (n − 1)d
  • Sum of n Terms (when d is known): Sₙ = n/2 [2a + (n − 1)d]
  • Sum of n Terms (when last term is known): Sₙ = n/2 (a + l)
  • Number of Terms: n = ((l − a) / d) + 1
  • Sum of First n Natural Numbers: Sₙ = n(n + 1) / 2
  • nth Term from the End: l − (n − 1)d [citation:7]
⚠️ Common Mistakes to Avoid:
  • Forgetting to subtract 1 from n in the nth term formula [citation:13]
  • Confusing the first term (a) with the common difference (d) [citation:13]
  • Not handling negative common differences correctly [citation:13]
  • Skipping intermediate steps in board exams [citation:13]
