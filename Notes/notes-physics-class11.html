Chapter 1: Units and Measurements

A foundational chapter dealing with physical quantities, systems of units, and the analysis of errors in measurement.

Learning Objectives

  • Understand the International System of Units (SI).
  • Apply dimensional analysis to check the correctness of equations.
  • Calculate absolute, relative, and percentage errors.
  • Determine significant figures in a measurement.

Key Concepts

  • Physical Quantity: A quantity that can be measured. It has a numerical magnitude and a unit (Q = nu).
  • Fundamental Units: Base units that are independent of each other (e.g., length, mass, time, electric current, temperature, amount of substance, luminous intensity).
  • Derived Units: Units obtained by multiplying or dividing fundamental units (e.g., velocity = m/s).
  • Significant Figures: The reliable digits in a measurement plus the first uncertain digit. They indicate the precision of measurement.

Important Definitions

  • Least Count: The smallest value that can be measured by a measuring instrument.
  • Accuracy: How close a measured value is to the true value.
  • Precision: How close the measured values are to each other (resolution of the instrument).

Dimensional Analysis

Dimensions represent the nature of a physical quantity. We use square brackets [ ] to denote dimensions.

  • Mass [M], Length [L], Time [T]
  • Velocity (v) = Displacement / Time = [L] / [T] = [L T⁻¹]
  • Acceleration (a) = Velocity / Time = [L T⁻¹] / [T] = [L T⁻²]
  • Force (F) = Mass × Acceleration = [M] [L T⁻²] = [M L T⁻²]

Principle of Homogeneity: In a correct physical equation, the dimensions of all the terms must be the same.

Important Formulae

  • Absolute Error (Δa): Δa = |True Value - Measured Value|
  • Mean Absolute Error: Δaₘₑₐₙ = (Σ|Δaᵢ|) / n
  • Relative Error: Δaₘₑₐₙ / aₘₑₐₙ
  • Percentage Error: (Relative Error) × 100%
  • Error in Product/Quotient: If Z = A × B or Z = A / B, then ΔZ/Z = (ΔA/A) + (ΔB/B)
  • Error in Power: If Z = Aⁿ, then ΔZ/Z = n × (ΔA/A)

Solved Example

Q: The resistance R = V/I where V = (100 ± 5) V and I = (10 ± 0.2) A. Find the percentage error in R.

Solution:
% error in V = (5/100) × 100 = 5%
% error in I = (0.2/10) × 100 = 2%
Since R = V/I, the relative errors add up.
% error in R = % error in V + % error in I = 5% + 2% = 7%

Answer: 7%

⚠️ Common Mistakes

Students often subtract errors when physical quantities are subtracted (e.g., Z = A - B). Remember that errors always add up to give the maximum possible error, so ΔZ = ΔA + ΔB, not ΔA - ΔB.

📌 Exam-Focused Points

  • Dimensional analysis cannot determine dimensionless constants.
  • Zeros between non-zero digits are always significant.
  • Trailing zeros in a number with a decimal point are significant.

Chapter 2: Motion in a Straight Line

Kinematics of a particle moving in one dimension under uniform and non-uniform acceleration.

Learning Objectives

  • Differentiate between distance and displacement.
  • Understand average/instantaneous velocity and acceleration.
  • Derive and apply the equations of kinematics for uniformly accelerated motion.
  • Analyze distance-time and velocity-time graphs.

Key Concepts

  • Displacement: Shortest distance from initial to final position (vector).
  • Distance: Total path length covered (scalar).
  • Instantaneous Velocity: Velocity at a specific instant of time. v = dx/dt.
  • Instantaneous Acceleration: Rate of change of velocity at a specific instant. a = dv/dt = d²x/dt².

Derivation of Kinematic Equations (Calculus Method)

Let acceleration 'a' be constant.

1. Velocity-Time Relation:
a = dv/dt ⇒ dv = a dt
Integrating both sides from t=0 (v=u) to t=t (v=v):
∫dv = ∫a dt ⇒ [v] = a[t] ⇒ v = u + at

2. Position-Time Relation:
v = dx/dt ⇒ dx = v dt = (u + at) dt
Integrating from t=0 (x=0) to t=t (x=s):
∫dx = ∫(u + at) dt ⇒ s = ut + ½at²

3. Position-Velocity Relation:
a = dv/dt = (dv/dx)(dx/dt) = v(dv/dx) ⇒ a dx = v dv
Integrating: ∫a dx = ∫v dv ⇒ as = ½(v² - u²) ⇒ v² = u² + 2as

Important Formulae

  • v = u + at (Velocity-time)
  • s = ut + ½at² (Displacement-time)
  • v² = u² + 2as (Velocity-displacement)
  • sₙ = u + a/2 (2n - 1) (Distance traveled in the nth second)
  • Variables: u = initial velocity (m/s), v = final velocity (m/s), a = constant acceleration (m/s²), t = time (s), s = displacement (m).

Solved Example

Q: A car moving with a speed of 50 km/h can be stopped by brakes after at least 6 m. If the same car is moving at a speed of 100 km/h, what is the minimum stopping distance?

Solution:
Using v² = u² + 2as, where final velocity v = 0.
0 = u² + 2as ⇒ s = -u² / 2a ⇒ s ∝ u² (since a is same).
s₂ / s₁ = (u₂ / u₁)² = (100 / 50)² = (2)² = 4
s₂ = 4 × 6 = 24 m

Answer: 24 m

⚠️ Common Mistakes

Using the kinematic equations when acceleration is NOT constant. These equations (v=u+at, etc.) only apply to uniform acceleration. If acceleration depends on time (e.g. a = 2t), you must use calculus (integration/differentiation) directly.

Chapter 3: Motion in a Plane

Vector algebra, resolution of vectors, projectile motion, and uniform circular motion.

Learning Objectives

  • Add and subtract vectors using geometric and analytical methods.
  • Resolve a vector into its rectangular components.
  • Analyze projectile motion (find time of flight, maximum height, and horizontal range).
  • Understand uniform circular motion and centripetal acceleration.

Important Definitions

  • Scalar: A quantity with magnitude only (e.g., mass, time, distance).
  • Vector: A quantity with magnitude and direction, obeying the triangle law of addition (e.g., velocity, force).
  • Projectile: An object thrown into space upon which the only acting force is gravity.

Projectile Motion Derivations

Consider a projectile launched with initial velocity u at an angle θ to the horizontal.

  • Horizontal component: u_x = u cosθ, a_x = 0
  • Vertical component: u_y = u sinθ, a_y = -g

1. Time of Flight (T):
Time to go up and come back down. Vertical displacement y = 0.
y = u_y t + ½ a_y t² ⇒ 0 = (u sinθ)T - ½ gT²
T = 2u sinθ / g

2. Maximum Height (H):
At max height, vertical velocity v_y = 0.
v_y² = u_y² + 2a_y H ⇒ 0 = (u sinθ)² - 2gH
H = u² sin²θ / 2g

3. Horizontal Range (R):
Horizontal distance covered in time T.
R = u_x × T = (u cosθ) × (2u sinθ / g) = u²(2 sinθ cosθ) / g
R = u² sin2θ / g

Important Formulae

  • Vector Addition (Magnitude): R = √(A² + B² + 2AB cosθ)
  • Vector Addition (Direction): tan α = (B sinθ) / (A + B cosθ)
  • Dot Product: A · B = AB cosθ = A_x B_x + A_y B_y + A_z B_z
  • Cross Product Magnitude: |A × B| = AB sinθ
  • Centripetal Acceleration: a_c = v² / r = ω²r

📌 Exam-Focused Points

  • For maximum horizontal range, the angle of projection must be θ = 45°. The max range is R_max = u²/g.
  • The range is the same for complementary angles of projection (θ and 90°-θ).
  • In uniform circular motion, the speed is constant but velocity changes continuously due to changing direction. Hence, there is always a centripetal acceleration directed towards the center.
