Chapter 4: Quadratic Equations High Weightage Chapter

Why this chapter is important? Quadratic equations are used to solve real-life problems involving speed, area, and profit. The discriminant and nature of roots are frequently tested in board exams. Expect 6-10 marks from this chapter.

1. Standard Form of a Quadratic Equation

A quadratic equation in the variable x is an equation of the form:

ax² + bx + c = 0

where:

  • a, b, c are real numbers
  • a ≠ 0 (if a = 0, it becomes a linear equation)
  • ax² is the quadratic term, bx is the linear term, c is the constant term

Examples

  • 2x² + 5x − 3 = 0 (a = 2, b = 5, c = −3)
  • x² − 4 = 0 (a = 1, b = 0, c = −4)
  • 3x² + 2x = 0 (a = 3, b = 2, c = 0)

Roots of a Quadratic Equation

A real number α is called a root of the quadratic equation ax² + bx + c = 0 if aα² + bα + c = 0.

A quadratic equation has at most two roots.

📌 Important Note: Every quadratic equation has exactly two roots (real or imaginary). But in Class 10, we only deal with real roots.

2. Methods of Solving Quadratic Equations

There are three main methods to solve a quadratic equation:

A. Factorisation Method (Splitting the Middle Term)

Steps:

  1. Write the equation in standard form: ax² + bx + c = 0.
  2. Find two numbers whose product = a × c and sum = b.
  3. Split the middle term using these two numbers.
  4. Group the terms and factor them.
  5. Equate each factor to zero and solve for x.
🔑 Solved Example: Solve x² − 5x + 6 = 0 by factorisation.

Step 1: a = 1, b = −5, c = 6. Product = 6, Sum = −5.
Step 2: Two numbers: −2 and −3 (product = 6, sum = −5)
Step 3: x² − 2x − 3x + 6 = 0
Step 4: x(x − 2) − 3(x − 2) = 0 ⇒ (x − 2)(x − 3) = 0
Step 5: x = 2 or x = 3

Answer: x = 2, 3

B. Completing the Square Method

Steps:

  1. Write the equation as ax² + bx = −c.
  2. Divide throughout by 'a' (if a ≠ 1).
  3. Add (b/2a)² on both sides.
  4. Write the LHS as a perfect square: (x + b/2a)².
  5. Take square root on both sides and solve for x.
🔑 Solved Example: Solve x² + 4x − 5 = 0 by completing the square.

Step 1: x² + 4x = 5
Step 2: Add (4/2)² = 4 on both sides: x² + 4x + 4 = 5 + 4
Step 3: (x + 2)² = 9
Step 4: x + 2 = ±3 ⇒ x = 1 or x = −5

Answer: x = 1, −5

C. Quadratic Formula Method

This is the most powerful method and works for all quadratic equations.

x = [−b ± √(b² − 4ac)] / 2a

where D = b² − 4ac is called the discriminant.

🔑 Solved Example: Solve 2x² − 7x + 3 = 0 using the quadratic formula.

Step 1: a = 2, b = −7, c = 3
Step 2: D = b² − 4ac = 49 − 24 = 25
Step 3: x = [7 ± √25] / 4 = [7 ± 5] / 4
Step 4: x = 12/4 = 3 or x = 2/4 = 1/2

Answer: x = 3, 1/2

3. Discriminant & Nature of Roots

The discriminant (D) of a quadratic equation ax² + bx + c = 0 is given by:

D = b² − 4ac

The value of D determines the nature of roots:

🎯 Three Cases of Discriminant:
  • D > 0: Two distinct real roots. The graph cuts the x-axis at two points.
  • D = 0: Two equal real roots (repeated root). The graph touches the x-axis at one point.
  • D < 0: No real roots (imaginary roots). The graph does not intersect the x-axis.

Roots Formula with Discriminant

x = [−b ± √D] / 2a

Sum and Product of Roots

If α and β are the roots of ax² + bx + c = 0, then:

α + β = −b/a

αβ = c/a
📌 Solved Example: Find the value of k for which the equation x² + kx + 9 = 0 has equal roots.

Solution: For equal roots, D = 0.
D = k² − 4(1)(9) = k² − 36 = 0
k² = 36 ⇒ k = ±6

4. Word Problems on Quadratic Equations

Quadratic equations are used to solve real-life problems. The key is to translate the problem into an equation and then solve it.

Common Types of Word Problems

  • Speed, Time, and Distance: Speed = Distance / Time
  • Area and Perimeter: Area = length × breadth
  • Age Problems: Present age, past age, future age
  • Work and Time: Work done in 1 day = 1/n
  • Number Problems: Consecutive integers, sum, product
🔑 Solved Example: The sum of squares of two consecutive positive integers is 365. Find the integers.

Solution: Let the integers be x and x + 1.
x² + (x + 1)² = 365
x² + x² + 2x + 1 = 365
2x² + 2x − 364 = 0
x² + x − 182 = 0
(x + 14)(x − 13) = 0
x = 13 or x = −14 (rejected, since integers are positive)

Answer: 13 and 14

Most Repeated Previous Year Questions

  1. Find the roots of the quadratic equation x² − 3x − 10 = 0. (2 Marks) — Answer: x = 5, −2.
  2. Find the value of k for which the quadratic equation kx² − 2kx + 6 = 0 has equal roots. (CBSE 2023) — Answer: D = 0 ⇒ 4k² − 24k = 0 ⇒ k = 0 or k = 6. Since k ≠ 0, k = 6.
  3. Solve for x: 2x² − 5x + 3 = 0. (2 Marks) — Answer: x = 3/2, 1.
  4. The sum of the reciprocals of Rehman's ages 3 years ago and 5 years from now is 1/3. Find his present age. (CBSE 2020) — Answer: 7 years.
  5. Find the nature of roots of the equation 3x² − 4√3x + 4 = 0. (2 Marks) — Answer: D = 48 − 48 = 0 ⇒ Two equal real roots.
  6. A train travels 360 km at a uniform speed. If the speed had been 5 km/h more, it would have taken 1 hour less for the same journey. Find the speed of the train. (CBSE 2019) — Answer: 40 km/h.
  7. Find the value of k for which the equation x² + k(2x + k − 1) + 2 = 0 has real and equal roots. (3 Marks) — Answer: k = 2 or k = −1/3.
  8. Solve the equation: 1/(x+4) − 1/(x−7) = 11/30, x ≠ −4, 7. (CBSE 2018) — Answer: x = 1, 2.
  9. If the roots of the equation (b − c)x² + (c − a)x + (a − b) = 0 are equal, prove that 2b = a + c. (3 Marks) — Answer: Set D = 0 and simplify.
  10. The diagonal of a rectangular field is 60 metres more than the shorter side. If the longer side is 30 metres more than the shorter side, find the sides of the field. (CBSE 2017) — Answer: Shorter side = 90 m, Longer side = 120 m.

Quick Revision — At a Glance

🎯 Key Formulas to Memorize:
  • Standard Form: ax² + bx + c = 0, a ≠ 0
  • Quadratic Formula: x = [−b ± √(b² − 4ac)] / 2a
  • Discriminant: D = b² − 4ac
  • Sum of Roots: α + β = −b/a
  • Product of Roots: αβ = c/a
  • Forming Equation: x² − (α + β)x + αβ = 0
🎯 Key Tips for Exam:
  • D > 0: Two distinct real roots
  • D = 0: Two equal real roots
  • D < 0: No real roots
  • Always check if the equation is in standard form before solving.
  • In word problems, reject negative or impossible values of x.
  • For "equal roots" questions, set D = 0 and solve for the unknown.
  • Factorisation is the fastest method if factors are easy to find.
Did You Know? The quadratic formula was known to ancient Babylonians (2000 BCE) and was later formalized by Indian mathematician Sridharacharya in the 9th century CE. In India, this formula is often called the "Sridharacharya Formula"!
